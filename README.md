# Interactive Web Development Quiz

An interactive quiz application built as part of Week 2 of my Web Development Internship at Next Gen Software Hub Pvt. Ltd.

## About the Project

This project is a web-based quiz that tests basic knowledge of HTML, CSS, and JavaScript.

Users can answer multiple-choice questions, receive immediate feedback, track their score, and restart the quiz after completing it.

## Features

- 10 multiple-choice questions
- HTML, CSS, and JavaScript questions
- Question counter
- Progress bar
- Instant correct/wrong answer feedback
- Live score tracking
- Final score display
- Restart Quiz option
- Responsive design
- Hover effects and smooth transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Events

## How It Works

1. The quiz starts with the first question.
2. The user selects one of the four answers.
3. The selected answer is checked using JavaScript.
4. The correct answer is highlighted.
5. The score is updated when the selected answer is correct.
6. The user clicks Next to continue.
7. After all 10 questions, the final score is displayed.
8. The user can click Restart Quiz to start again.
